# TriplD Component Guide

Status: All requested TriplD components are installed in `apps/web` as local shadcn-generated source; the four short registry names were installed through their current `-shadcnui` registry IDs.

| Component | Where to use it |
| --- | --- |
| `@uitripled/native-tooltip-shadcnui` | Use it for brief helper labels on icon controls in the app shell, workflow canvas, node inspector, asset actions, and task rows. |
| `@uitripled/native-dialog-shadcnui` | Use it for confirmations, asset details, unavailable capability explanations, export readiness gates, and account or workspace actions. |
| `@uitripled/native-typewriter-shadcnui` | Use it for lightweight creative text reveals on entry, project-start, script preview, and storyboard draft surfaces. |
| `@uitripled/native-magnetic-shadcnui` | Use it for subtle pointer response on primary calls to action, project mode choices, and featured asset or workflow cards. |
| `@uitripled/native-start-now-shadcnui` | Use it as the primary start-project action on the entry page and project-start flow. |
| `@uitripled/native-hover-card-shadcnui` | Use it for rich previews of projects, nodes, assets, tasks, and history metadata where the base content stays visible. |
| `@uitripled/glowy-waves-hero-shadcnui` | Use it only for the first entry or project-start hero surface. |
| `@uitripled/image-slider-card` | Use it for compact media comparisons, generated image examples, project mode previews, and export review highlights. |
| `@uitripled/cards-slider` | Use it for small horizontal rails of recent projects, saved workflows, or featured production examples. |
| `@uitripled/dynamic-tag-cloud` | Use it for prompt vocabulary, style tags, genre tags, node capability tags, asset metadata, and filter suggestions. |
| `@uitripled/preview-details-card` | Use it for reusable project, asset, node, generation attempt, history, and export preview cards with key metadata. |
